<h2>📖 Description</h2>
<p>This repository contains all the practical assignments and coding implementations I completed during my <strong>Data Structures</strong> course (<strong>01AI0304</strong>) in the <strong>3rd semester</strong> of my <strong>BTech CSE (AIML)</strong> program at <strong>Marwadi University</strong>, Rajkot.</p>
<p>All programs are written in <strong>C language</strong> and cover fundamental data structures concepts including arrays, sorting, searching, stacks, queues, linked lists, trees, graphs, and hashing as per the university syllabus.</p>

<hr/>

<h2>🎯 Course Objectives</h2>
<ol>
    <li>To understand different data structures and algorithms.</li>
    <li>To solve problems using data structures such as linear lists, stacks, queues, binary trees, and graphs and writing programs for these solutions.</li>
    <li>To efficiently implement the different data structures and solutions for specific problems.</li>
</ol>

<hr/>

<h2>✅ Course Outcomes</h2>
<p>After completion of this course, student will be able to:</p>
<ol>
    <li><strong>Understand</strong> — Learn the different types of data structures, operations on them and applications.</li>
    <li><strong>Apply</strong> — Choose the appropriate data structure and algorithm for a specified application.</li>
    <li><strong>Analyse</strong> — Analyse various sorting and searching techniques with applications.</li>
    <li><strong>Create</strong> — Implement linear data structures such as stacks, queues, linked lists and their applications.</li>
    <li><strong>Create</strong> — Implement non-linear data structures such as trees, graphs and their applications.</li>
</ol>
